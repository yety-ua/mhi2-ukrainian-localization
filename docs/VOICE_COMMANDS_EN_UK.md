# Голосовий помічник: англійські фрази (паралельний список)

Помічник слухає й говорить **англійською** (`en_GB`), навіть коли інтерфейс українською. Тому фрази, які треба **вимовляти**, на екрані показано англійською, а інструкції для користувача (наприклад, "натисніть кнопку мовлення") лишаються українськими. Нижче англійський рядок з екрана і його український зміст (колишній український переклад цього рядка).

Згенеровано з маніфесту `review-command-hints-english-20261106.json` (збірка v1.1.0).
